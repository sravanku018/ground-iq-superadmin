Doctrine: One Motion Language

[G] ONE SYSTEM Two skins, one grammar: field = emerald #059669 with black text on primary (daylight contrast); portal = Google #1a73e8 white-on-blue. Both share the same hover lift, active settle, and 2px focus ring.
[A] 44px MINIMUM Every touchable button is ≥44px tall (small = 34px, pointer-only portal rows excepted). Focus-visible always shows the outline — keyboard and switch users never lose the button.
[T] TACTILE, NOT LOUD Hover lifts 1px with a soft shadow; active presses back down. No scale jumps, no color strobe. Disabled = 50% opacity, cursor changes, handlers stay bound so screen readers announce why.
[A] DESTRUCTIVE = DANGER + CONFIRM Delete draft, End survey, Remove project never fire on a single tap — danger buttons route through the confirm dialog (see modals.html). Portal danger tints first, fills solid on hover.
