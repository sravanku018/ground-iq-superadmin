Implementation Pattern

useRowAction hook — optimistic flip + rollback
// src/hooks/useRowAction.js export function useRowAction(items, setItems) { return useCallback(async (id, action, payload) => { // 1. Snapshot for rollback const prev = items.find(r => r.id === id) const snapshot = prev ? { ...prev } : null // 2. Optimistic flip — UI updates instantly setItems(rs => rs.map(r => r.id === id ? { ...r, status: action, ...payload } : r )) // 3. Background sync try { await fetch(`/api/review/${id}`, { method: 'PATCH', body: JSON.stringify({ status: action }) }) } catch (err) { // 4. Rollback on failure setItems(rs => rs.map(r => r.id === id ? { ...snapshot } : r )) toast('Sync failed — reverted', 'error') } }, [items, setItems]) }

Doctrine: Twitter's Optimistic UI

[T] OPTIMISTIC Loren Brichter's Tweetie: tap like → instant, sync later. Confirm fires immediately. The user sees the result before the network roundtrip. Feels fast because it IS fast.
[T] ROLLBACK If the server rejects, the row reverts to its previous state. Snapshot before flip, restore on failure. The user sees a brief flash — honest about the failure, not hiding it.
[G] BUILT FOR THE LOW END On a bad network, the rollback is more likely. But the UI never blocks. The surveyor or admin keeps working. The network catches up when it can.
