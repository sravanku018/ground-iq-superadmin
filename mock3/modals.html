Doctrine: One Exit Pattern

[G] THREE OVERLAYS, NOT FOUR Passive nudges = bottom sheet. Irreversible actions = centered confirm. Deep object views = right drawer. Anything else bends back into one of these — no ad-hoc popups.
[A] ALWAYS AN EXIT Every overlay closes on Esc and on overlay click (drawer + confirm); the update sheet adds an explicit Later. role="dialog" + aria-modal on drawers and confirms so screen readers trap scope.
[T] MOTION TELLS THE TRUTH Sheet slides up 16px (it came from below), drawer slides in from the right (it came from the list), confirm pops 4% (it interrupts). 180–300ms, ease-out — felt, not seen.
[A] DESTRUCTIVE ≠ PRIMARY COLOR Confirm's dangerous action is the red one, always right-aligned, and the safe action is never styled primary. The dialog names the object (“Telangana Pre-Poll 2026”) so a wrong tap is readable before it lands.
