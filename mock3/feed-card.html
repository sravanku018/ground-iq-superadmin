Doctrine: ONE Card, Three Contexts

[T] ONE CARD FeedCard is the single card component for Report feed, Audit log, and Scorecards. Same structure: avatar → name → pills → trust ring → status. The eye learns one pattern.
[T] EXPLAINABLE Click any card → trust pillar breakdown expands. "Why this score?" is always one tap away. No opaque algorithm — the score is derived from signals the platform already collects.
[T] OPTIMISTIC Confirm/Reject fires instantly. Card flips status. Background sync + rollback on failure. "Tap → instant, network catches up." The syncing card with dashed border shows network state.
[G] ONE SYSTEM Same component, same tokens.css, same trust ring. Admin portal and field app read as one product. No re-deciding the card layout per screen.
